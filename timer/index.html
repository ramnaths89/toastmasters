How to use
  1. Pick a segment — or set Green / Amber / Red with ± or by typing.
  2. Enter the speaker's name (optional — blank auto-fills as "PS 1", "TT 2", …).
  3. Start — screen & centre word show WHITE → GREEN → AMBER → RED, then BELL when the overtime bell rings (set the seconds after Red with the ± beside the bell).
  4. Stop, then Reset — Reset logs the speaker (name · segment · time) and clears for the next.
  5. Click any logged name or time to edit it. Copy exports the list · ✕ removes a row (asks first). While running you can still edit the name and the log; only Stop and the Bell stay active.
  6. Pick the bell sound — Desk Bell, Chime or Beep. On a phone, tap Test once before the meeting starts: that unlocks audio and confirms it's loud enough for the room.
