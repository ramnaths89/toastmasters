How to use
  1. Pick a segment — or set Green / Amber / Red with ± or by typing.
  2. Enter the speaker's name.
  3. Press Start — the screen goes white, then green → amber → red at your times; bell 30s after red.
  4. Press Stop, then Reset — Reset logs the speaker (name · segment · time) and clears for the next.
  5. Copy exports the list · ✕ removes a row · Test checks the bell.
While the timer runs, only Stop and the Bell toggle stay active.
